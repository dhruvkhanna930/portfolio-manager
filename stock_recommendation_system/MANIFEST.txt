MODEL INFORMATION
=================
GRU 1-Day Model:
  - Architecture: Gated Recurrent Unit
  - Input: 30-day price lookback
  - Output: 1-day prediction (0-100 score)
  - Training Data: Qantas historical prices
  - File Size: ~500 MB

LSTM 5-Day Model:
  - Architecture: Long Short-Term Memory
  - Input: 60-day price lookback
  - Output: 5-day prediction (0-100 score)
  - Training Data: Qantas historical prices
  - File Size: ~500 MB
