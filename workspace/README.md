# Portfolio Manager

Single-user portfolio tracker for Stocks, Mutual Funds, and Bonds. See `CLAUDE.md`
for the full product spec, architecture, and build roadmap.

This is currently **scaffolding only** — no features are implemented yet.

## Prerequisites

- Python 3.11+
- Node 18+
- npm

## Running locally

The backend and frontend run as two separate processes. Open two terminals.

### Terminal 1 — backend (Flask API, port 5000)

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
python app.py
```

API will be available at `http://localhost:5000`. Health check:
`http://localhost:5000/api/health` → `{"status": "ok"}`.

Swagger UI (auto-generated by flask-smorest): `http://localhost:5000/docs`.

### Terminal 2 — frontend (React + Vite, port 5173)

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

App will be available at `http://localhost:5173`.

## Environment variables

- `backend/.env.example` — `DATABASE_URL` (defaults to local SQLite), news API
  keys, Flask env, price sync interval. See CLAUDE.md §11.
- `frontend/.env.example` — `VITE_API_BASE_URL`, pointing at the backend above.

Copy each `.env.example` to `.env` in its own folder before running — `.env` files
are gitignored and never committed.

## Project structure

- `backend/` — Flask app factory, routes → services → models (see CLAUDE.md §10)
- `frontend/` — React 18 + Vite + Tailwind, dark theme (see CLAUDE.md §9)
- `CLAUDE.md` — single source of truth for product spec, schema, and conventions
